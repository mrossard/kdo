* application KDO


** objectif :

applications de gestion de listes de cadeaux / projets de cadeaux à offrir


** contraintes techniques à respecter absolument :

- php 8.5
- symfony 8
- bulma CSS
- htmx

On utilise exclusivement HTMX pour enrichir le contenu, et on évite au maximum le javascript en-dehors de ça.
On utilise exclusivement bulma pour les CSS, sauf si ce qu'on veut faire n'est pas prévu par bulma.
